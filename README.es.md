# PBZ Auto QTE

[🇬🇧 English](README.md) · [🇵🇱 Polski](README.pl.md) · [🇫🇷 Français](README.fr.md) · **🇪🇸 Español** · [🇺🇦 Українська](README.uk.md)

Un mod de accesibilidad para **Phantom Blade Zero** (PC) que **supera los QTE por ti** durante los combates.

> ♿ **Este mod se creó pensando en las personas con discapacidad motora.** Los QTE exigen una pulsación rápida, pulsaciones repetidas o mantener una tecla. Si te resulta difícil o imposible, el mod lo hace por ti.

> ⚠️ **Se necesita una versión oficial del juego, comprada legalmente, para que el mod funcione.**

Funciona con [PBZ Auto Parry & Dodge](https://github.com/Muspelion/PBZ-AutoParryDodge), [PBZ Auto Weapon Switch](https://github.com/Muspelion/PBZ-AutoWeaponSwitch) y [PBZ Auto Sprint](https://github.com/Muspelion/PBZ-AutoSprint). Cada mod se instala por separado.

## ✨ Qué hace

- Lee qué tecla espera el QTE, también cuando el juego la elige al azar.
- Gestiona pulsaciones simples, repetidas y largas.
- Se detiene en cuanto el juego indica éxito o fallo.
- No modifica el juego: solo añade archivos junto a él.

## 🚀 Instalación

1. Descarga **`PBZ-AutoQTE-v1.0.0.zip`** desde la página [Releases](../../releases/latest) y descomprímelo.
2. Cierra el juego y haz doble clic en **`install.bat`** (si Windows avisa: *Más información → Ejecutar de todas formas*).
3. Inicia el juego. Al cargar una partida verás `Auto QTE: ON`.

## 🎮 Controles

| Tecla | |
|---|---|
| **F3** | Auto QTE activado / desactivado |

## 🗑️ Desinstalación

Cierra el juego y haz doble clic en **`uninstall.bat`**.

## ⚠️ Limitaciones

- Los QTE de las escenas cinemáticas usan otro sistema y no están cubiertos.
- Probado solo en la versión de Steam `CL-301524_JKS-17219`. El instalador admite Epic Games Store, pero no se ha probado.
- Una actualización del juego puede hacer que el mod deje de funcionar.
