# PBZ Auto QTE

**🇬🇧 English** · [🇵🇱 Polski](README.pl.md) · [🇫🇷 Français](README.fr.md) · [🇪🇸 Español](README.es.md) · [🇺🇦 Українська](README.uk.md)

An accessibility mod for **Phantom Blade Zero** (PC) that **passes on-screen QTEs for you** during fights.

> ♿ **This mod was created with players with motor disabilities in mind.** QTEs need a fast press, fast repeated presses or a long hold. If that is hard or impossible for you, this mod does it for you.

> ⚠️ **An official, legally purchased version of the game is required for the mod to work.**

Works with [PBZ Auto Parry & Dodge](https://github.com/Muspelion/PBZ-AutoParryDodge), [PBZ Auto Weapon Switch](https://github.com/Muspelion/PBZ-AutoWeaponSwitch) and [PBZ Auto Sprint](https://github.com/Muspelion/PBZ-AutoSprint). Each mod can be installed on its own.

## ✨ What it does

- Reads which key the QTE is waiting for, also when the game draws it at random.
- Handles single presses, repeated presses and long presses.
- Stops as soon as the game reports success or failure.
- Nothing in the game is modified: the mod only adds files next to the game.

## 🚀 Installation

1. Download **`PBZ-AutoQTE-v1.0.0.zip`** from the [Releases](../../releases/latest) page and unpack it.
2. Close the game and double-click **`install.bat`** (if Windows warns: *More info → Run anyway*).
3. Start the game. After loading a save you will see `Auto QTE: ON`.

## 🎮 Controls

| Key | |
|---|---|
| **F3** | Auto QTE on / off |

## 🗑️ Uninstall

Close the game and double-click **`uninstall.bat`**.

## ⚠️ Limits

- QTEs inside film scenes use another system and are not handled.
- Tested only on the Steam version `CL-301524_JKS-17219`. Epic Games Store is supported by the installer but not tested.
- A game update can stop the mod from working.
